# 毕方内容生产助手

毕方 BFTOOLS 团队的内容运营桌面工具。选择要做的文章，再沿着找对标、生成草稿、人工检查、保存或导出的路径完成工作。当前团队仓库只面向 Windows 上的 CSDN 技术文章与百家号长文章。

## 适合做什么

- **CSDN 技术文章：** 选择主题或参考资料，生成后检查事实、代码与来源，再编辑、保存或导出。
- **百家号长文章：** 围绕主题整理参考、生成草稿，人工核对事实与表达后再保存或导出。
- **对标与风格：** 采集已加载的公开作品与可见指标；缺失指标保持“未提供”，再由使用者选择参考作品或保存写作风格。

小红书不属于当前团队仓库的发行范围。[LydiaTools 的 NoteSignal](https://github.com/LydiaTools/notesignal) 是另外一款个人开源选题研究插件，不是本产品的安装包。

AI 生成由使用者接入自己的服务。工具不附带 API Key 或免费额度；成稿需要人工检查。

## 负责与反馈

这是毕方团队产品。Lydia 负责运营工具的推广与用户沟通，产品与源码发布由团队维护。

如果你正在做 CSDN 或百家号长文章，可以[提交具体的内容生产场景](https://github.com/mercedesbestsupplier-maker/mercedesbestsupplier-maker/issues/new?template=content-production-feedback.md)：写明平台、卡住的步骤、现在怎样处理，以及想得到什么结果。已参加内部测试的使用者，也可以补充版本和复现步骤。反馈会作为公开 GitHub Issue 出现；提交场景不代表获得内部测试资格。

不使用 GitHub 时，国内更新与交流可从[团队主页的社媒入口](../../README.md#内容与社媒)找到。
