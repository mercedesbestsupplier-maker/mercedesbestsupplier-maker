## BFTiles · Windows 窗口布局

BFTiles helps people arrange multiple Windows windows, save layouts for repeated work, and bring the right windows back into view. It is a commercial company product.

多应用、多窗口、多账号工作时，用 BFTiles 整理窗口排布、保存常用布局，并在需要时继续使用。实际功能、适用版本和获取方式以[项目页](https://github.com/mercedesbestsupplier-maker/BFTiles)为准。
